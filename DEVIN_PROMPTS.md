# Suggested Devin Chat prompts

Use these in Devin Chat as part of your real build/review workflow. Keep a note of what Devin actually does and include that in your final submission.

1. "Review this repository as a student-life productivity product. Explain the user problem, current architecture, and the three highest-impact improvements that can be completed quickly."
2. "Inspect the task manager UI and JavaScript. Find bugs in task creation, completion, filtering, persistence and empty states. Implement fixes and explain changed files."
3. "Review server.js for the Notion API integration. Check that secrets remain server-side, validate inputs, handle Notion API errors, and suggest safe improvements."
4. "Create a manual QA checklist for the dashboard, tasks, events, study tracker and career hub. Run any checks available in this environment and report actual results."
5. "Improve mobile responsiveness and keyboard accessibility without changing the core product behavior."

Do not state that Devin performed work unless you actually ran the prompt and observed the result.
